# StorageShrink 📱

تطبيق Flutter لتحسين مساحة التخزين بالذكاء الاصطناعي

## تحميل الـ APK

1. انتقل إلى تبويب **Actions** في هذا الـ repository
2. اضغط على آخر workflow run ✅
3. انزل لقسم **Artifacts**
4. حمّل **StorageShrink-APK**

## بناء محلي

```bash
flutter pub get
flutter gen-l10n
flutter run
```

## المميزات
- 🔍 فحص الملفات الباردة (30/60 يوم)
- 🗜️ ضغط WebP / HEIC / ZIP
